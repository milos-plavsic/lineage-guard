# Submission package

- `devpost.md` — copy for the Devpost project page.
- `video-script.md` — time-coded 2:40 demonstration script.
- `demo-runbook.md` — deterministic and live recording paths.
- `architecture.md` — system diagram and boundaries.
- `disclosures.md` — pre-existing work, tools, licensing, and data disclosure.
- `acceptance-matrix.md` — requirement-by-requirement proof and external gates.
- `screenshot-plan.md` — actual-product capture list and privacy review.
- `submission.json` — final public URLs and video duration; intentionally incomplete until hosting.

Run `uv run python scripts/audit_submission.py` to see the remaining submission gates.
